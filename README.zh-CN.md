# 48小时 MAP–NEE 联合轨迹研究核心代码

本仓库公开 MIMIC-IV v3.1、eICU-CRD v2.0 数据提取核心查询，以及队列构建、
联合轨迹、死亡关联、竞争风险累计发生率、条件信息和增量分析的核心计算代码。

数据库提取部分仅包含 MIMIC 和 eICU，不含本地医院提取程序。研究采用独立
48小时 landmark 设计：纳入 T0 后48小时仍存活且在院者，使用此前48小时的
血流动力学记录，评价 landmark 后结局。

目录和运行要求见 [英文说明](README.md)；时间定义及输入约束见
[analysis_contract.md](docs/analysis_contract.md)。分析代码按结果模块组织。

仓库仅包含代码和说明，不包含患者数据、数据库连接凭据、患者级结果或稿件。
使用者须自行取得数据库授权。这里公开的是计算核心及提取查询，不是包含全部
数据准备、模型初始化对象和拟合参数的一键复现流水线。
